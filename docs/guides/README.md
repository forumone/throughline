# How-to guides

Recipes. Each guide is a specific task with a clear end state. They assume you've read enough of the [concepts](../concepts/) to know *why* — they tell you *how*.

- **[Adding a collection](adding-a-collection.md)** — model new content (Programs, People, Posts) so it's editable through Claude
- **[Authoring component contracts](authoring-component-contracts.md)** — write good contracts that make Claude reason well
- **[Theming emails](theming-emails.md)** — brand the approval emails
- **[Adding an integration](adding-an-integration.md)** — implement an `Integration` (CRM, analytics, marketing automation)
- **[Configuring approvers](configuring-approvers.md)** — define groups, write a `groupResolver` against your real users
- **[Customizing accessibility checks](customizing-accessibility-checks.md)** — add policies that gate publishing
- **[Migrating content](migrating-content.md)** — bring an existing site's content into Throughline
- **[Upgrading core packages](upgrading-core-packages.md)** — track and apply Throughline updates safely
- **[Building a plugin](building-a-plugin.md)** — when none of the above fit, add a Payload plugin of your own
